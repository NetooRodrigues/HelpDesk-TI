# HelpDesk TI

Sistema web de gerenciamento de chamados de suporte técnico desenvolvido para praticar desenvolvimento web com Python.

## Tecnologias utilizadas

- Python
- Flask
- SQLite
- HTML5
- CSS3
- Git e GitHub

## Funcionalidades

- Criação de chamados
- Listagem de chamados
- Visualização de detalhes
- Edição de chamados
- Alteração de status para resolvido
- Exclusão de chamados
- Definição de prioridade
- Registro de data e hora
- Dashboard com indicadores
- Layout responsivo
